# Réserve

Passages et figures **retirés du texte publié** parce qu'ils ne sont pas assez solides, et gardés
pour être repris. Rien de ce dossier n'est rendu sur le site.

Chaque fiche dit : ce qu'était l'exercice, où sont conservés le code et les données, les critiques
qui l'ont fait retirer, et ce qu'il faudrait pour le republier. Le texte retiré y est reproduit à
l'identique.

Un passage en réserve n'est pas un état du droit ni un résultat : on ne le cite pas, on ne le
reprend pas dans un chapitre sans avoir levé les critiques de sa fiche.
