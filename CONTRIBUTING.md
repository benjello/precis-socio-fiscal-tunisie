# Contribuer au précis

Le précis est un travail en cours. Il s'améliore par ceux qui connaissent le terrain : cadres des
caisses et des administrations, universitaires, praticiens. **Aucune compétence technique n'est
nécessaire** — un message suffit.

## Ce qui nous aide le plus

- **Signaler une erreur** : un taux, une date, une référence, une formulation qui prête à confusion.
  Dites où (volume, section), ce qui est écrit, ce qui devrait l'être, et d'où vous le tenez.
- **Indiquer ou transmettre un document** qui ne se trouve pas au *Journal officiel* : rapport
  d'activité d'une caisse, annuaire statistique, circulaire, note commune, étude, thèse, mémoire.
  Une simple indication de l'endroit où il se trouve est déjà précieuse.
- **Relire un chapitre** de votre domaine et dire ce qui est faux, daté ou obscur.
- **Dire ce qui manque** : un plan mal fait, un niveau de détail inadapté, une question que l'ouvrage
  devrait traiter.

## Comment le faire

**Par message.** Si vous avez reçu un message de l'auteur, répondez-y simplement : votre remarque
sera consignée dans le suivi public du projet, pour qu'elle ne se perde pas.

**Par un ticket**, si vous avez un compte GitHub ou acceptez d'en créer un : chaque page du précis
porte un lien « Faire part d'un problème », qui ouvre un ticket sur
[la page de suivi](https://github.com/benjello/precis-socio-fiscal-tunisie/issues). Écrivez-y en
français ou en arabe.

**Par une modification directe**, pour qui le souhaite : le lien « Modifier cette page » ouvre le
fichier source. Les modifications se proposent sur les fichiers français (`precis/fr/`) ; la version
arabe en est dérivée et ne se modifie pas à la main. Les règles d'écriture sont dans
[`docs/conventions-redaction.md`](docs/conventions-redaction.md).

## Ce que nous demandons à une contribution

- **Une source** : un texte, un document, une publication. L'ouvrage ne retient aucune valeur ni
  aucune date sans source vérifiée ; une case vide vaut mieux qu'une valeur plausible.
- **Un ton documentaire** : le précis décrit le droit et son évolution ; il ne le juge pas.

## Reconnaissance

Les contributeurs sont remerciés nommément dans l'ouvrage, **s'ils le souhaitent** : nul n'y est
cité sans son accord. Un retour donné à titre personnel n'est jamais présenté comme la position
d'une institution.
